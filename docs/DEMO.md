# 시연 순서 (Pleos Connect v2.1.0 AVD)

서울역 → 판교 → 기흥역 시연 경로를 에뮬레이터 GPX 재생으로 달린다.
앱은 **Pleos FusedLocation**으로 위치를 받는다. 판교 진입과 기흥역 도착은 위치 변화와 Pleos 근접 알림(ENTER/EXIT) 중 먼저 들어온 것으로 판정한다.
Pleos 내장 내비는 AVD에서 위치와 남은 시간이 바뀌지 않으므로 시연에 쓰지 않는다.
앱 왼쪽(창이 좁으면 위쪽)의 경로 그림이 지도를 대신한다.

## 준비물

- `tools/demo-route.gpx`: 경로 그림과 같은 좌표다. 1배속 재생 시 40분 걸린다.
  - 판교 진입: 1배속 약 22.6분, 3배속 약 7.5분, 5배속 약 4.5분
  - 경로 좌표를 바꿀 때는 `app/src/main/assets/demo_trip.json`의 `route`를 수정한 뒤 `python3 tools/make_demo_gpx.py`로 GPX를 다시 만든다.
- 이 GPX의 경로는 고속도로 축을 대략 따라 그린 시연용 선이다. 실제 내비 경로가 아니다.

## 순서

1. AVD는 Cold Boot로 켠다.
2. 에뮬레이터 `⋯`(Extended controls) → **Location**에서 시작 위치를 정한다.
   - 단일 지점을 서울역(37.55594, 126.97233)으로 지정한다.
   - 이 단계를 거치지 않으면 이전 재생의 끝점(기흥역)에서 시작할 수 있다. 첫 실제 위치가 반경 안이면 그 지역/도착은 한 번 반경 밖으로 나갈 때까지 무시되지만 화면이 어색하다.
3. 앱을 실행한다. 첫 실행 시 나오는 Pleos 위치 권한 요청에서 **허용**을 누른다.
   - 왼쪽(창이 좁으면 위쪽) 경로 그림 카드의 둘째 줄이 `Pleos 위치 수신 중 · 기흥역까지 40분`이면 된다. 좌표는 브리핑 화면(주차 모드)의 작은 상태 줄에 나온다.
4. 주행 전 화면에서 브리핑을 시작한다. **일반 브리핑이 먼저 재생 중이어야 한다.**
5. Location의 Routes에서 `tools/demo-route.gpx`를 불러온다. 3~5배속으로 재생하고, Virtual Console에서 기어를 D로 바꾼다.
6. 판교 반경(1.65km)에 들어서면 경로 패널에 `판교 진입 · 지금 이야기가 끝나면 지역 브리핑으로 넘어가요`가 나온다. 듣던 조각이 끝나면 진입 안내 멘트와 판교 브리핑이 이어진다.
7. 기흥역 반경 300m에 들어서면 도착 처리된다. 기어를 P로 바꾸면 **오늘의 발견**과 **도착 후 퀴즈**가 열린다.

## 위치가 들어오지 않을 때 (백업)

- 에뮬레이터 Location 단일 지점을 판교 직전 `37.41632, 127.09543` → 판교 `37.40159, 127.10842` → 기흥역 `37.27566, 127.11595` 순서로 옮긴다(각각 반영될 때까지 몇 초 대기).
- 시뮬레이션 입력의 `판교 진입 직전(으)로 이동`, `기흥역 근처(으)로 이동`도 남아 있다. 판교 진입 버튼은 없으므로 판교 전환은 위 Location 방식으로 보인다.
- 도착은 한 번 처리되면 반경을 벗어나도 유지된다. 해제하려면 앱을 다시 실행한다.
- 실제 위치가 수신되는 동안에는 약 3초마다 실제 위치가 버튼으로 옮긴 위치를 덮어쓴다. 백업 버튼은 위치를 받지 못할 때만 쓴다.

## 성장 단계(포인트) 보여 주기

- 포인트는 기기에 저장돼 앱을 다시 켜도 유지된다.
- 녹화 전에 P단 톱니바퀴 → 시뮬레이션 입력에서 `포인트 초기화` → `다음 단계 직전`을 누른다(새싹까지 5P 남은 295P). 일반 조각 하나를 끝까지 들으면 새싹이 된다.
- `포인트 +100`은 다른 단계(줄기 등)를 보여 줄 때 쓴다. 시연용 포인트는 '이번 주행' 포인트에 넣지 않는다.
- 도착 팝업에 `이번 주행 +N 포인트 · 지금 🌱 새싹 Lv.2`와, 이번 주행에서 단계가 오르면 `새싹(으)로 자랐어요!`가 나온다.

## 알려진 제약

- 남은 시간은 목적지까지 남은 직선거리에 비례해 추정한다. 기준은 서울역 출발 40분이다.
  - 배속 재생 중에는 화면의 분과 실제 경과 시간이 맞지 않는다. 판교 이후 브리핑이 끝나기 전에 도착할 수 있고, 퀴즈는 끝까지 들은 조각만 출제한다.
- TTS 음성 떨림은 에뮬레이터 오디오 문제다(같은 AVD의 다른 앱에서도 동일).
