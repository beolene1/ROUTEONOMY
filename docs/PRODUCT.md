# ROUTEONOMY 제품 명세

기준 문서: `docs/ROUTEONOMY 기획안 · 스토리텔링 명세 · 기능 명세.pdf` (2026-11-06). 이번 개발 결정: 1차는 Pleos Connect v2.1.0 에뮬레이터, 서버 없이 로컬 JSON, 임시 UI, F1~F7과 도착 후 퀴즈까지 구현한다. 11월 14일까지 시연 가능, 11월 15일 제출.

## 제품
반복되는 이동 시간을 남은 시간과 주변 지역에 맞춘 경제·산업 음성 브리핑으로 채우고, 도착 후 오늘의 발견을 돌아본다. 투자 권유를 하지 않고 산업과 개념을 설명한다. 지도와 경로 안내는 Pleos 내비게이션 앱이 담당한다.

## 기능과 완료 조건
- **F1 기어 모드:** D/R/N이면 주행, P면 주차 상태가 된다. 실제 Vehicle API를 우선 사용하고, 연결 불가 시 별도 Fake 입력으로 검증한다.
- **F2 ETA:** NaviHelper로 잔여 시간·거리 변경을 반영하며 목적지가 없으면 15분을 기본값으로 쓴다. 시뮬레이션에서 ETA를 수동 변경할 수 있다.
- **F3 플래너:** WRAPUP 분량과 1분 여유를 먼저 확보하고 관심 분야 MAIN을 예산 안에 고른다. ETA 변경 시 재생 중 항목은 유지하고 미재생 항목만 재계획한다. 3분 이하이면 wrap-up으로 전환한다.
- **F4 음성:** 선택한 세그먼트를 순서대로 TTS 재생한다. 일시정지/다음 동작 및 재생 중복·중단 처리를 확인한다. 기기 기본 TTS를 우선 사용한다.
- **F5 지역 진입:** 지정 반경 진입 이벤트를 감지해 현재 항목 종료 후 REGION을 삽입한다. 한 주행의 지역별 최대 1회. MVP는 판교 1곳이며 Fake 이벤트도 제공한다.
- **F6 주행 UI:** 주행 중 큰 잔여 시간과 현재 주제, 다음·일시정지 조작만 표시한다. 지도/애니메이션/세부 탐색을 제공하지 않는다.
- **F7 오늘의 발견:** 안전한 주차 상태에서 해당 세션의 들은 주제, 키워드, 용어 하나, 원문 링크를 표시한다.
- **도착 후 퀴즈:** 실제 목적지 도착 상태가 확인된 뒤에만 주차 화면에서 세션 콘텐츠를 바탕으로 퀴즈를 시작하고 답·결과를 보여준다. 도착 이벤트가 없는 MVP 환경에서는 시뮬레이션 도착 입력으로 시연한다.

## 콘텐츠 모델
JSON 세그먼트: `id`, `type`(MAIN/REGION/WRAPUP), `topic`, `script`, `durationSec`, `industries[]`, `keywords[]`, `term`(용어/설명), `regionId?`, `sources[]`, `status`(DRAFT/APPROVED). 샘플 데이터는 APPROVED로 제공한다. 원문 링크는 출처 표시에 쓰고 기사 전문을 재배포하지 않는다.

## 상태와 안전
기어(P/D/R/N)와 목적지 도착 여부는 다른 상태다. P단 진입만으로 도착 또는 퀴즈 가능 상태로 간주하지 않는다. F7은 P에서 표시할 수 있지만 퀴즈는 도착 완료 상태에서만 허용한다. 시연 시뮬레이터는 `도착 처리`를 별도 입력으로 제공한다. 실제 목적지 도착 판정 API가 SDK에서 확인되지 않으면 이를 Fake-only 동작으로 표시한다.

## 1차 범위 제외
Spring 서버, 콘텐츠 동기화/수집 배치, 관심 분야 설정 UI, 주간 기록, 실시간 주가, 음성 질의, 실시간 LLM, 차량 제어, 종목 추천은 제외한다. 디자인 확정 대기 없이 임시 UI를 쓴다.
