# ROUTEONOMY 제품 명세

기준 문서: `docs/ROUTEONOMY 기획안 · 스토리텔링 명세 · 기능 명세.pdf` (2026-11-06). 이번 개발 결정: 1차는 Pleos Connect v2.1.0 에뮬레이터, 서버 없이 로컬 JSON, 임시 UI, F1~F7과 도착 후 퀴즈까지 구현한다. 11월 14일까지 시연 가능, 11월 15일 제출.

2026-11-11 기획 변경: '남은 시간 맞춤 브리핑'(F2·F3)과 '지역 진입 브리핑'(F5)을 경로 구간 분할 브리핑 하나로 통합한다. 이 문서의 F2·F3·F5와 콘텐츠 모델은 변경 후 기준이며, 원본 PDF와 다른 부분은 이 문서를 따른다.

## 제품
반복되는 이동 시간을 경로에 맞춘 경제·금융 음성 브리핑으로 채우고, 도착 후 오늘의 발견을 돌아본다. 경로 위의 지정 지역에 들어서기 전에는 사용자에게 맞춘 일반 금융·산업 지식을, 들어선 뒤에는 그 지역과 연결된 금융·산업 이야기를 들려준다. 투자 권유를 하지 않고 산업과 개념을 설명한다. 지도와 경로 안내는 Pleos 내비게이션 앱이 담당한다.

## 기능과 완료 조건
- **F1 기어 모드:** D/R/N이면 주행, P면 주차 상태가 된다. 실제 Vehicle API를 우선 사용하고, 연결 불가 시 별도 Fake 입력으로 검증한다.
- **F2 경로·구간 시간:** 현재 위치→목적지 경로에 미리 지정한 지역이 있으면 경로를 두 구간으로 나누고 각 소요 시간을 얻는다. A 구간은 현재 위치→지역 진입, B 구간은 지역 진입→목적지다. 경로에 지정 지역이 없으면 목적지까지 남은 시간 하나만 쓰고, 목적지가 없으면 15분을 기본값으로 쓴다. MVP는 로컬 JSON 더미 경로 시나리오로 시연하며, 시뮬레이션에서 현재 구간 시간을 수동 변경할 수 있다. 실제 경로·시간 SDK 연동은 더미와 같은 입력 계약으로 나중에 교체한다.
- **F3 구간별 플래너:** 구간마다 따로 분량을 계획한다.
  - A 구간: 일반 금융·산업 MAIN을 'A 시간 − 1분 여유' 안에서 관심 분야 순으로 고른다. 지역 진입 즈음 A 브리핑이 끝나도록 하기 위해서다.
  - B 구간: 해당 지역 REGION 항목(지역 부동산·금융 정보, 최신 소식, 지역 키워드와 연결된 신사업 소식)을 'B 시간 − WRAPUP 분량 − 1분 여유' 안에서 고르고 마지막에 WRAPUP을 둔다.
  - 지정 지역이 없는 경로는 단일 구간으로 WRAPUP 분량과 1분 여유를 먼저 확보하고 MAIN을 고른다.
  - 시간 변경 시 재생 중 항목은 유지하고 현재 구간의 미재생 항목만 재계획한다. (기존 '3분 이하이면 wrap-up 전환' 규칙은 2026-11-11 사용자 결정으로 MVP에서 적용하지 않는다.)
- **F4 음성:** 선택한 세그먼트를 순서대로 TTS 재생한다. 일시정지/다음 동작 및 재생 중복·중단 처리를 확인한다. 기기 기본 TTS를 우선 사용한다.
- **F5 지역 진입 전환:** 경로 위 지정 지역 진입을 감지하면 재생 중인 A 항목을 끝까지 들은 뒤 B 구간 브리핑으로 전환한다. 남은 A 항목은 재생하지 않고 완주 기록에도 넣지 않는다. A 브리핑이 진입 전에 끝나면 '지역 진입 대기'를 표시한다. 한 주행에서 지역별 전환은 최대 1회다. MVP 지역은 판교 1곳이며(데이터 구조는 여러 지역을 허용), 진입은 시뮬레이션 패널의 Fake '판교 진입' 입력으로 시연한다.
- **F6 주행 UI:** 주행 중 큰 잔여 시간과 현재 주제, 다음·일시정지 조작만 표시한다. 지도/애니메이션/세부 탐색을 제공하지 않는다.
- **F7 오늘의 발견:** 안전한 주차 상태에서 해당 세션의 들은 주제, 키워드, 용어 하나, 원문 링크를 표시한다.
- **도착 후 퀴즈:** 실제 목적지 도착 상태가 확인된 뒤에만 주차 화면에서 세션 콘텐츠를 바탕으로 퀴즈를 시작하고 답·결과를 보여준다. 도착 이벤트가 없는 MVP 환경에서는 시뮬레이션 도착 입력으로 시연한다.

## 콘텐츠 모델
JSON 세그먼트: `id`, `type`(MAIN/REGION/WRAPUP), `topic`, `script`, `durationSec`, `industries[]`, `keywords[]`, `term`(용어/설명), `regionId?`, `sources[]`, `status`(DRAFT/APPROVED). `type`의 의미: MAIN은 A 구간(또는 단일 구간)의 일반 금융·산업 브리핑, REGION은 `regionId` 지역의 B 구간 브리핑, WRAPUP은 마무리다. 샘플 데이터는 APPROVED로 제공하고, 팀이 작성한 원고(예: 'AI 시대, 반도체가 중요한 이유')를 우선 쓰며 부족한 항목은 더미로 채운다. 원문 링크는 출처 표시에 쓰고 기사 전문을 재배포하지 않는다.

더미 경로 시나리오 JSON: `id`, `origin`, `destination`, `regionId?`, `minutesToRegion`(A), `minutesRegionToDestination`(B). 지역 JSON: `id`, `name`, `latitude`, `longitude`, `radiusMeters`. MVP 시나리오는 '서울역 → 판교 → 정자역' 1개다. 시연 시간이 길어지지 않도록 구간 시간과 스크립트는 짧게 둔다.

## 상태와 안전
기어(P/D/R/N)와 목적지 도착 여부는 다른 상태다. P단 진입만으로 도착 또는 퀴즈 가능 상태로 간주하지 않는다. F7은 P에서 표시할 수 있지만 퀴즈는 도착 완료 상태에서만 허용한다. 시연 시뮬레이터는 `도착 처리`를 별도 입력으로 제공한다. 실제 목적지 도착 판정 API가 SDK에서 확인되지 않으면 이를 Fake-only 동작으로 표시한다.

## 1차 범위 제외
Spring 서버, 콘텐츠 동기화/수집 배치, 관심 분야 설정 UI, 주간 기록, 실시간 주가, 음성 질의, 실시간 LLM, 차량 제어, 종목 추천은 제외한다. 디자인 확정 대기 없이 임시 UI를 쓴다.
